# CSS Mini-Projects

A collection of small projects built to practice and demonstrate CSS techniques. Each project lives in its own folder and includes the files needed to view it locally.

## Projects

### [Sidebar Demo](Sidebar%20Demo/)

A full-screen photography landing page with a CSS-only slide-out navigation menu.

- **Open:** [Sidebar Demo/mini_index.html](Sidebar%20Demo/mini_index.html)
- **Details:** [Sidebar Demo/README.md](Sidebar%20Demo/README.md)

## Getting started

1. Browse to a project folder.
2. Open its HTML file in a web browser.
3. Check that project's README for features and any external resources it uses.

These are standalone front-end practice projects; no build setup is currently required.
